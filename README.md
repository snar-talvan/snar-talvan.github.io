# Talvan

Talvan er amboð til stóra skíggjan í flokkinum, gjørt til [Snar](https://snar.fo). Hon verður víst á [snar.fo/talvan](https://snar.fo/talvan).

- `index.html` – Talvan sjálv
- `telefon.html` – telefonsíðan, har lærarar kunnu broyta sínar talvur
- `svar.html` – næmingasíðan til livandi spurnarkanningar
- `hundur.html` – Snar-hundurin
- `pdfjs/` – PDF.js 3.11.174

Talvan lá áður á katof.github.io/rokning-spol/talvan og varð flutt hagar 17.11.2026.
